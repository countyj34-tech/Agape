Place short notification audio files here (MP3/WAV) to enable richer alerts in the app.

Recommended file names (referenced by the app):
- notify.mp3            — general notification (used by StoreContext / guest marketplace)
- notification.mp3      — generic notification used by NotificationCenter
- order-alert.mp3       — sound for new orders
- promotion-alert.mp3   — sound for promotions
- item-alert.mp3        — sound for new items

If these files are missing the app will fall back to a short WebAudio beep.
